# SHFS 教務系統

> 調代課申請審核、鐘點費結算與巡堂異常會辦一體化系統（適用國小、國中、高中、高職）。

## 系統特色

- **高職專業實習連堂防呆檢核**：支援 3~4 節實習連堂自動連動，實習工場安全等級與設備配置即時比對。
- **智慧排代推薦**：依據同科專長、基本授課節數、空堂時段與超額時數媒合代課教師。
- **教學組一鍵核定與通知單套印**：支援「調課/代課/補課申請單」與「派代通知單」列印與匯出。
- **主計出納結算總表**：超鐘點、課輔、代課、代導師印領清冊與 Excel 報表。
- **巡堂與異常會辦**：課間／課輔／段考巡堂、SMTP 通知、電子核章與校長每周彙整。
- **教學組名冊彈性維護**：支援一人兼辦或多人分工，簽章即時同步。
- **本機＋雲端同步**：LocalStorage 持久化，可選學校雲端同步。

## 🚀 部署至 GitHub Pages

本專案已內建 GitHub Actions 自動部署工作流程。

1. 在 GitHub 儲存庫進入 **Settings** ➔ **Pages**。
2. 將 **Build and deployment** ➔ **Source** 選擇為 **GitHub Actions**。
3. 系統將自動編譯並部署至 `https://<您的帳號>.github.io/SHFS/`。

> **巡堂 SMTP 寄信（建議校內常開電腦）**  
> GitHub Pages 只適合平常瀏覽，**不能寄信**。請在校內電腦：
>
> 1. 安裝 **Node.js（LTS）** 後，在專案根目錄雙擊 **`start-mail-host.bat`**
>    （`啟動寄信主機.bat` 相同；**不必**裝 Python）
> 2. 瀏覽器開 `http://那台IP:3000`（**不要**開 github.io）
> 3. 寄信設定：API 根網址**留空**；SMTP 用 `smtp.gmail.com:587`
>
> 若視窗一閃就關：多半沒裝 Node，或 bat 不在專案根目錄（需與 `package.json` 同層，並 `git pull` 完整專案）。
>
> 操作電腦可與寄信主機不同台，但網址都要指向寄信主機的 `:3000`。  
> Render 免費方案會封鎖 SMTP，不建議再用。

## 💻 本地端開發 (Local Development)

```bash
# 安裝相依套件
npm install

# 啟動開發伺服器（含寄信 API）
npm run dev

# 專案打包編譯
npm run build

# 正式環境（靜態頁 + 寄信 API 同站；校內寄信請用此方式）
npm start

# Windows 亦可雙擊專案根目錄「啟動寄信API.bat」
```
